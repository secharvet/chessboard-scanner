# Référentiel des ouvertures (codes ECO et noms)

Fichiers `a.tsv` à `e.tsv` : copie du référentiel public **lichess-org/chess-openings** (licence CC0, domaine public),
colonnes `eco`, `name`, `pgn`. Utilisé par `scripts/db/nommer-eco.mjs` pour donner à chaque position de la base son code
ECO et son nom officiel (traduit en français), affichés en tête dans l'assistant, à côté de nos propres noms et textes.
